# Barco Maldito: Roguelike de Expediciones

Juego roguelike por turnos hecho en Streamlit.

## Ejecutar local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Subir a GitHub y Streamlit Cloud

1. Crea un repositorio en GitHub.
2. Sube `app.py`, `requirements.txt` y este `README.md`.
3. En Streamlit Cloud selecciona el repo y usa `app.py` como archivo principal.

## Guardado

La partida se guarda localmente en `save_barco_maldito.json` dentro del mismo proyecto.
