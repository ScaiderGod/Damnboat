# Barco Maldito: Roguelike de Expediciones

Juego roguelike por turnos hecho en Streamlit.

## Qué incluye

- Menú principal con puerto, expedición, inventario, mejoras, tripulación, estadísticas y ayuda.
- Recursos visibles en todos los menús.
- Varios puertos desbloqueables.
- Mapa por expedición.
- Salas de combate, élite, jefe, tienda, mercado negro, tesoro, evento, tormenta, ruinas, NPC, descanso, santuario y trampa.
- Combate RPG por turnos con probabilidad de golpe, fallo, crítico, reparación y escape.
- Vista visual de tu barco contra barcos o enemigos distintos.
- Recursos por rareza.
- Inventario ampliable.
- Reliquias pasivas y consumibles.
- Mejoras permanentes por rareza.
- Tripulación mejorable.
- Guardado local automático.

## Cómo correrlo

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Guardado

La partida se guarda localmente en:

```text
save_barco_maldito.json
```

Ese archivo se crea automáticamente cuando juegas.
